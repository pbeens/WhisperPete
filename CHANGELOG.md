# Changelog

## [1.0.1] - 2026-08-30

Maintenance release.

- Fixed the Buy Me a Coffee link so it opens in the default browser.

## [1.0.0] - 2026-08-30

Initial public release of WhisperPete for Windows.

- Local Parakeet speech-to-text transcription.
- Global `Alt+Shift+Space` start/stop hotkey.
- Completed transcriptions copied to the Windows clipboard.
- Resizable popup window with version and support information.
